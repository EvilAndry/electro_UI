# Сортувальник — інтерактивні схеми

Статичний сайт (HTML + CSS + JS, без збірки й залежностей) з чотирма пов'язаними видами:

| Вид | Що показує |
|---|---|
| **Електрична** | Принципова схема: ввід, захист, групи приводів, драйвери відвідників, кола керування (щаблі L–N) |
| **Логічна** | Функціональні блоки, логічні вузли «І» / «АБО», потоки енергії та сигналів |
| **Шафа** | Фізичне розміщення апаратів у шафі (за фото), кабельні короби, гофра, двері |
| **Сортувальник** | Загальний вигляд лінії збоку: зони, модулі, табло, приводи, відвідники, кабельна траса |

Наведіть курсор або торкніться будь-якого елемента чи кабелю, і той самий елемент, усі його кабелі та
сусідні апарати підсвітяться **на всіх видах одночасно**. Елементи шафи на виді «Сортувальник»
підсвічують саму шафу пунктиром.

* колесо миші, щипок двома пальцями або кнопки `+ −` — масштаб; перетягування — зсув; `⤢` — показати все; `◎` — до виділеного;
* **Ланцюг** — підсвітити весь шлях живлення та керування (від мережі до споживача);
* **Маркування** — завжди показувати номери кабелів на фізичних схемах;
* **1 / 2** — одна схема або дві поруч (на телефоні завжди одна, інформація в нижній панелі);
* `/` — пошук, `Esc` — зняти виділення;
* посилання з виділенням можна скопіювати з адресного рядка (`#el=QF305&v=cab,elec`).

## Публікація на GitHub Pages

1. Створіть репозиторій і завантажте в корінь вміст цієї папки (`index.html`, `css/`, `js/`, `.nojekyll`).
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch**, гілка `main`, папка `/ (root)`.
3. За хвилину сайт буде доступний за адресою `https://<користувач>.github.io/<репозиторій>/`.

Локально можна просто відкрити сайт через будь-який статичний сервер, наприклад `python -m http.server`.

## Як редагувати дані

Усе, що бачите на схемах, бере дані з одного файлу: **`js/data.js`**.

* **Елемент** — `{ id, name, model, type, loc, parent, desc, assumed, mark }`.
* **Кабель** — `{ id, from, to, kind, cond, phase, phys, mark, exit }`.

### Маркування (коли з'являться бирки)

```js
// елемент
C({ id: 'QF1', mark: '-QF1', name: 'Вводний автомат', ... });

// кабель: номер + колір бирки
cb({ id: 'W1', mark: { num: '12', color: 'red' }, from: 'GRID', to: 'QF1', ... });
// або лише номер
cb({ id: 'W2', mark: { num: '13' }, ... });
```

Щойно `mark` заповнено, на всіх схемах замість службового `id` показується реальне маркування,
а в панелі інформації — колір бирки. `id` лишається внутрішнім ключем: не змінюйте його.

### Інші налаштування

* `phys` — фактичний колір проводу чи оболонки на фізичній схемі (`'#8b5a2b'`, `'white'` тощо);
* `assumed: true` — елемент є припущенням: малюється пунктиром і має позначку в панелі;
* `GROUP_DEF` — групи приводів: фаза та зони, які живить кожна група; `BREAKERS_PER_GROUP` — кількість автоматів у ряду;
* розташування на кресленнях задається у файлах `js/view-*.js` (функції `layout()` / `put()` / `at()`).

## Важливо

Це **чернетка**, складена за трьома фотографіями. Моделі апаратів узято з видимих написів
(IEK ВА47-29 C50, DigiTOP VP-3F40A, Hager CFA463D / ESC363 / ESC325 / ESC125 / MCN120, DigiTOP TK-3,
ETI CRM-91H, VC-411, підписи «Монітори», «Принтера», «Роб. стіл», «Сканера», «Світло»), а от
призначення реле часу, кнопок і ламп на дверях, кількість автоматів у рядах, розподіл груп за зонами
та трасування кабелів — це припущення. Перевірте їх на місці й виправте в `js/data.js`.

## Структура

```
index.html
css/style.css
js/data.js         — дані (елементи, кабелі, логічні зв'язки)
js/svg.js          — SVG-хелпери, умовні позначення, маршрутизація
js/view-elec.js    — електрична схема
js/view-logic.js   — логічна схема
js/view-cab.js     — фізична схема шафи
js/view-sorter.js  — фізична схема сортувальника
js/app.js          — підсвічування, масштаб, панелі, пошук
```
